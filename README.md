## Project Overview
This is a simple static website for **NOAH INTERNATIONAL MINISTRIES**. It provides:

- Information about the church and its ministries  
- Sermons and upcoming events  
- A contact form for visitors  

The website is built with **HTML, CSS, and basic JavaScript**.

---

## Files Included
- `index.html` – Home page  
- `about.html` – About page  
- `contact.html` – Contact page with form  
- `events.html` – Events page  
- `style.css` – Stylesheet  
- `images/` – All website images  
- `.gitignore` – Prevents large files from being uploaded  

---

## How to View
1. Clone or download the repository.  
2. Open `index.html` in a web browser to view the website.
